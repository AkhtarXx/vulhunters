# Security policy

## Supported development line

Security fixes are made against the current default branch while the project is under active development.

## Reporting a vulnerability

Do not disclose a potential vulnerability in this repository through a public issue, discussion, or pull request. Contact the repository maintainers through a private channel and include:

- a clear description of the issue and affected version or commit;
- a minimal reproduction or proof of concept;
- expected and observed behavior;
- impact assessment and any suggested mitigation.

Please do not include private keys, API credentials, live-target access details, or user data in a report. Maintainers will acknowledge the report, investigate it, coordinate a fix where appropriate, and agree on disclosure timing with the reporter.

## Tooling limitation

VulnHunters produces audit evidence and research leads. Its reports are not a security certification and must not be used as the sole basis for deploying or accepting a smart-contract system.
